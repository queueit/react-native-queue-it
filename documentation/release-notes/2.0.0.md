# 2.0.0

- iPhone now runs on Queue-it's Swift SDK. iOS 15 or later is required.
- The old test switch `QueueIt.enableTesting` is replaced by your app's own waiting-room domain. The test domain is passed the same way: `waitingRoomDomain: '<customerId>.test.queue-it.net'`.
- Check for a pass before showing the waiting room, with `tryPass*` and `showQueue`.
- Invite codes for invite-only waiting rooms.
- The `queueUrlChanged` event and `QueueIt.isEventAvailable`.
- Error codes in `userInfo.errorCode`, with more errors reaching your app on iPhone.
- Your event listeners are kept after a failed `run*` call.
- On iPhone and Android, the waiting room remembers a visitor's place on the phone. A new run soon after a pass can reuse it and, past the room's limit, show "Rejected queue number", so keep the visitor's pass for the session.

2.0.0 has changes that your app must make. Read the [upgrade guide](https://github.com/queueit/react-native-queue-it/blob/master/documentation/UPGRADING.md) before upgrading.
